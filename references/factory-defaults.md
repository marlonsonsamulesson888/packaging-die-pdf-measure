# 厂内默认口径（可按本厂调整）

以下是本厂刀模绘制标准里与测量有关的默认值。脚本只用到其中的颜色、双压痕间距和出血，其余用于人工解读。换厂、换纸、换刀模厂时先改这里再用。

| 项目 | 默认值 | 说明 |
|---|---|---|
| 切线颜色 | 红 | 来稿常见红切、绿/蓝压痕；单色刀模必须人工分层 |
| 压痕颜色 | 蓝（来稿也常见绿） | 标注线应在独立图层、颜色不同 |
| 尺寸口径 | 压痕线中心 | 盒名尺寸 = 面板压痕中心尺寸，写 L×W×H |
| 双压痕判定 | 两压痕间距 ≤ 6mm | 3–4.5mm 常见，等于让位纸厚的若干倍 |
| 内折墙 | 外墙高 H − 2t | t 为纸厚；内折墙明显短于 H−2t 多半是给底舌或扣位让位 |
| 天地盖配合量 | 天盖 = 地盖 + 宽 4、长 5、高 1 | 单边间隙一般 0.5–1.5；不对称要问 |
| 出血 | 切线外扩 3mm | 刀模未画出血时由设计稿补，内折墙露边也要铺 |
| 文字安全距 | 距切线、压痕 ≥3mm | 印前复核另有完整清单 |
| 开窗 | R≥3（常用 R5），窗边距最近压痕 ≥10mm | 窗口是部件内部的闭合切线 |
| 测量精度 | 报 ±0.5mm | PDF 坐标精度高于实际刀模，别报到 0.01 |

## 结论用词
- “刀模成盒约 A×B×C mm（AI 测量，待人工确认）”
- “与声称 X×Y×Z 不符，只有 Z 一致，需确认用哪个”
- “未画出血线，设计按 3mm 外扩补”
- 纸厚不知道时：“内尺寸待纸厚确认，不报具体数”
