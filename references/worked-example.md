# 示例：两件天地盖刀模（已匿名）

来稿：一个 891×834mm 版面，两件部件，红切线、绿压痕，客户参考图标“200×47×235”。

```bash
python scripts/measure_die.py die.pdf --claimed 200x47x235 --md 记录.md
```

脚本结果（摘要）：

| 部件 | 底面（压痕中心） | 外墙 | 双压痕间距 | 内折墙 | 内折墙压痕线长 |
|---|---|---|---|---|---|
| 1 天盖 | 70.2×245.1 | 54.8–55.2 | 4.0 | 53.1 | 长边 238.3 / 短边 65.6 |
| 2 地盖 | 65.3×235.0 | 51.0–51.3 | 3.7 | 49.4 | 长边 228.6 / 短边 61.0 |

- 配合量：宽 +4.9、长 +10.2、墙高 +3.9。长方向配合量是宽方向的两倍，和厂内“宽 4、长 5”口径不符，要问师傅。
- 地盖端墙压痕线长 64.4，比底面宽 65.3 短 0.9，是端墙两侧的让位。
- 成盒外尺寸约 245×70×55，和声称的 200×47×235 三个数都对不上：刀模很可能属于另一款产品，或参考图标的是别的口径。不自行选择，交老板确认。
- 没有出血线，设计时补 3mm。

教训：同一份刀模，人工目测时容易把“地盖长 235”当成整盒长度、把内折墙压痕线长 228.6 当成底面。先跑脚本拿到每一条压痕线，再写结论。
